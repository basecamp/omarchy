# What is Omarchy Kids?

Omarchy Kids is a variation of Omarchy Linux for kids. This includes features, themes, plugins, and more. 

We're [discussing](https://discord.com/channels/1390012484194275541/1544325032724009052) how to ensure the computer, and the things it has access to, are safe, fun, and educational for Omarchy Kids users. 

# ground rules (via DHH)

1. sudo is needed to change settings etc.
2. Let's focus on the kids younger than 13 first.
3. Kids mode is triggered during initial install. Right now we let you setup for another owner when you go it Ctrl + C on the keyboard select screen. That changes such that the first Q is a full Who is this computer for? 1) Me, 2) Child,3) Another owner
