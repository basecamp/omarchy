# Plugin Workbench shell integration

This first-party shell surface is adapted from [tcballard/omarchy-plugin-workbench](https://github.com/tcballard/omarchy-plugin-workbench) at commit `4bdab3c7e477f475766f138f7085c42f03ba5586` under the MIT License.

The `omarchy-plugin-workbench` package provides the helper executable. Omarchy owns the panel copy so its shell contract, keyboard behavior, and visual language can evolve with the first-party shell.
