# Discovery shell integration

This first-party shell surface is adapted from [tcballard/omarchy-plugin-workbench](https://github.com/tcballard/omarchy-plugin-workbench) under the MIT License. Apps, plugins, and themes are normalized as Discovery flavours; the plugin development lifecycle remains available under Build.

The `omarchy-discovery` package provides the helper executable. Omarchy owns the panel copy so its shell contract, keyboard behavior, and visual language can evolve with the first-party shell.
